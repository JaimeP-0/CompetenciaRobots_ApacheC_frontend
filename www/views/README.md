# Vistas HTML (`www/views/`)

Cada ruta en `js/routes.js` apunta a un archivo aquí: `views/{ruta}.html`

## Carpetas

| Carpeta | Contenido |
|---------|-----------|
| `public/` | Catálogo e inicio (participantes) |
| `registro/` | Pantalla de verificación (jueces) |
| `admin/` | Login y panel de administración |
| `checklists/` | Fragmentos de tablas por categoría |

## Ejemplos

- `#/` → `public/inicio.html`
- `#/registro` → `registro/registrar.html`
- `#/admin/equipos` → `admin/equipos.html`
